# Hands-on Robot Learning (Fall 2026)

Static course website built with Astro + Starlight. Content is primarily Markdown/MDX plus small YAML files for structured data.

## Quick edits

- Schedule: `src/data/schedule.yaml`
- Assignments: `src/data/assignments.yaml`
- Readings: `src/data/readings.yaml`
- Docs pages: `src/content/docs/**`

## Requirements

- Node.js `>=22.12.0`
- npm `>=10`

## Commands

| Command           | Action                                   |
| :---------------- | :--------------------------------------- |
| `npm install`     | Install dependencies                      |
| `npm run dev`     | Start local dev server (`localhost:4321`) |
| `npm run build`   | Build production site to `./dist/`        |
| `npm run preview` | Preview the production build locally      |
