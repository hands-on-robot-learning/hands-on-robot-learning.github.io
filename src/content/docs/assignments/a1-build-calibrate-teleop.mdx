## What you will learn

- How to bring up a physical robot safely and repeatably
- How calibration and configuration errors show up as “weird behavior”
- How to gather evidence (logs + video) for debugging in later assignments

## Required hardware/software

- SO-101 follower arm kit (shared course hardware)
- Fixed external camera (minimum)
- LeRobot tooling (course stack)

## Deliverables

<ul className="hol-deliverable-checklist">
	<li>Assembled SO-101 follower arm</li>
	<li>Motor ID and calibration files</li>
	<li>Safe home pose and soft-limit configuration</li>
	<li>Camera detection and preview check</li>
	<li>Short continuous video showing safe teleoperation</li>
	<li>One-page notes file describing known issues, repairs, or deviations</li>
</ul>

## Evaluation protocol

- Demonstrate teleoperation on the assembled arm using the configured safe home pose and safety limits.
- Provide evidence artifacts (video + configuration files + notes) so the setup can be reproduced.

## Common failure modes

<aside className="hol-assignment-callout hol-assignment-callout--failure">
	<h3>Common failure modes</h3>
	<ul>
		<li>Incorrect motor ID mapping or calibration leading to reversed or saturated joints</li>
		<li>Unsafe velocities or missing soft limits</li>
		<li>Camera not detected, wrong device selection, unstable mount, or inconsistent lighting</li>
		<li>Drift/backlash/latency that makes teleoperation “look fine” but produces unreliable data</li>
	</ul>
</aside>

## How to get unstuck

<aside className="hol-assignment-callout hol-assignment-callout--tip">
	<h3>Debugging tips</h3>
	<ul>
		<li>Reduce to a minimal “smoke test” (home pose → small motion → stop) before longer teleop sessions.</li>
		<li>Record short, continuous videos of failures and annotate what you changed between attempts.</li>
		<li>Ask for help early if you suspect a hardware fault; do not “push through” unsafe behavior.</li>
	</ul>
</aside>

## Extension ideas

- Add a clear version tag to calibration/config files and track changes across attempts.
- Establish a repeatable camera mount position and document it with a photo/diagram.
- Create a short checklist your team runs before any autonomous scripts.
