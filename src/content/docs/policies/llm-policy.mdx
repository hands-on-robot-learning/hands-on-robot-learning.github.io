---
title: LLM / coding-assistant policy
description: Permissive use with attribution, understanding, and responsibility.
---

Students may use LLMs/coding assistants such as **ChatGPT, Claude, Copilot, Codex**, and similar systems.

## Allowed uses

- Explaining concepts
- Debugging errors
- Generating starter code
- Refactoring code
- Writing documentation
- Drafting experiment plans
- Brainstorming failure hypotheses
- Implementing code-as-policies-style robot programs
- Improving clarity of reports

## Requirements

1. Disclose the tool used
2. Briefly describe how it was used
3. Test and understand generated code
4. Cite external code/models/datasets suggested by the tool
5. Avoid uploading private/sensitive/privileged information

## Not allowed

- Fabricating results
- Inventing numbers
- Hiding manual interventions
- Generating fake logs/videos
- Submitting code the team cannot explain
- Misrepresenting contribution
- Uploading private/PII data

Teams are responsible for everything they submit.
