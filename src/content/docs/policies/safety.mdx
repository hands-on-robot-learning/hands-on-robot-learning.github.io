SO-101 is a small robot arm, but it is still a **physical robot**. Treat it like lab equipment.

<aside className="hol-safety-alert">

	<p>
		{
			'Before any policy, script, or VLA-style system moves the robot on its own, confirm the workspace, robot configuration, stop plan, and first-run limits.'
		}
	</p>
</aside>

## Safety rules

<ul className="hol-safety-rules">
	<li>Keep hands clear during autonomous execution.</li>
	<li>Use safe home poses and velocity limits.</li>
	<li>Keep workspaces clear.</li>
	<li>Stop immediately if robot behaves unexpectedly.</li>
	<li>Report damaged hardware promptly.</li>
	<li>Do not bypass safety limits for leaderboard performance.</li>
	<li>Power down before mechanical adjustments.</li>
	<li>Check cables before motion scripts.</li>
	<li>Keep liquids away.</li>
</ul>

## Autonomous execution checklist

<ul className="hol-safety-checklist">
	<li>Workspace clear: no loose tools, cables, clutter, or bystanders in the motion area.</li>
	<li>Camera(s) connected, stable, and pointed at the expected workspace.</li>
	<li>Correct robot configuration loaded.</li>
	<li>Safe home pose defined and reachable.</li>
	<li>Velocity limits set conservatively.</li>
	<li>Emergency stop plan ready: know exactly how you will stop motion.</li>
	<li>First run at low speed with a short horizon.</li>
</ul>

## Damaged hardware

<aside className="hol-policy-callout">
