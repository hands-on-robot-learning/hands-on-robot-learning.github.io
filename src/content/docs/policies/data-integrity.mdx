## Official trials

For official trials:

- Use the assigned protocol
- Record continuous unedited video
- Do not manually intervene
- Report required trials, not only successes
- Distinguish practice vs official runs
- Describe deviations

## Dataset cards

Dataset cards should report:

- Number of episodes
- Number of valid episodes
- Cameras used
- Robot configuration
- Task definition
- Collection protocol
- Known issues
- Data source

## Model/checkpoint reporting

Model/checkpoint reporting should include:

- Architecture
- Pretrained checkpoint
- Training data
- Steps/epochs
- Hyperparameters
- Trained/finetuned/evaluated status
- Known failure modes

## Videos

- Official evaluation videos must be continuous and unedited.
- Edited highlight reels must not be presented as official evaluation.

Honest failures are acceptable.
