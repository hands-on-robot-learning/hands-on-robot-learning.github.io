## Official trial protocol

<ol className="hol-protocol-list">
	<li>
		<strong>Reset scene</strong>
		<span>Place the cube, robot, cameras, and workspace in the assigned start configuration.</span>
	</li>
	<li>
		<strong>Start recording</strong>
		<span>Begin continuous video before the policy starts moving.</span>
	</li>
	<li>
		<strong>Run policy</strong>
		<span>Run the baseline, learned policy, or VLA-style system without manual intervention.</span>
	</li>
	<li>
		<strong>Record success/failure</strong>
		<span>Success means the cube reaches the target zone within the time limit.</span>
	</li>
	<li>
		<strong>Log intervention/no intervention</strong>
		<span>Any human correction, reset, or rescue must be recorded.</span>
	</li>
	<li>
		<strong>Save continuous video</strong>
		<span>Official trial videos should be continuous and unedited.</span>
	</li>
	<li>
		<strong>Report all trials</strong>
		<span>Report the full official set, not only successful runs.</span>
	</li>
</ol>
