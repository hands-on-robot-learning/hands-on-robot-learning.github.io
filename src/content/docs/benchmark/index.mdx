The shared benchmark in this course is **cube pick-and-place** with the **SO-101** arm.

## Task

Pick up a cube and place it into a marked target zone/bin.

## Canonical setup

- SO-101 follower arm
- Fixed external camera
- Wrist camera when available
- Printed workspace mat
- Standard cube
- Standard target zone/bin
- Safe home pose
- Fixed evaluation protocol

## Official evaluation

- 10 trials
- Success if cube is placed within time limit without human intervention

## Metrics

- Successes out of 10
- Median successful completion time
- Number of interventions
- Dataset size for low-data awards
- Failure taxonomy

## Leaderboard philosophy

The leaderboard is meant to be fun and motivating. It is **not** the primary basis for grades.
