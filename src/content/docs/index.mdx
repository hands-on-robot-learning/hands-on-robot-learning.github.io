Hands-on Robot Learning is a project-heavy robotics course where teams build SO-101 robot arms, collect teleoperation data, train imitation-learning policies, and evaluate them on a shared benchmark.

## Course arc

1. Build the robot.
2. Engineer a baseline.
3. Teach from demonstrations.
4. Try a generalist policy.
